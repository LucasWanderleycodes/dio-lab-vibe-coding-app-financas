# 🖥️ PC-Master Planner: Finanças com Vibe Coding

## 🎯 Conceito do App
Este app foi desenvolvido como desafio da DIO 4.0 para ajudar a equilibrar gastos fixos e lazer, mantendo o foco em uma meta de compra futura (um computador novo). O diferencial é um **Agente de IA** que atua como mentor, sugerindo microajustes diários no orçamento para garantir que o sonho do PC seja realizado sem sacrifícios desnecessários.

## 🤖 Meu Prompt Final (PRD)
Abaixo está o briefing estruturado que utilizei como base para a IA (Copilot):

> "Aja como um Product Manager e especialista em IA. Estou desenvolvendo um conceito de aplicativo via Vibe Coding. O app chama-se PC-Master Planner. O objetivo é equilibrar: Contas Fixas + Reserva para o PC + Gasto com Lazer. O app deve ter um Agente de IA que analisa se o gasto com lazer vai atrasar a compra do PC e sugere ajustes automáticos."

## 💡 Reflexão sobre o Processo
* **O que funcionou bem:** A capacidade da IA de transformar um desejo simples ("comprar um PC") em uma lógica financeira de "Quanto posso gastar hoje".
* **O que não funcionou como esperado:** Entender que a IA precisa de limites claros para não sugerir cortes irreais no orçamento de lazer.
* **O que aprendi sobre IAs:** No Vibe Coding, a clareza da minha intenção no prompt é o que define se o código gerado será útil ou apenas genérico.
